3c:T750,"Resize a PDF" means two genuinely different things and people mean both, so this page offers both over the same dropped file and lets you switch between them without uploading it twice. Page size changes the physical sheet: choose A3, A4, A5, Letter, Legal or Tabloid, portrait or landscape, and either scale the page content to fit the new sheet and centre it or change the page box only and let a smaller sheet crop into the content. It is the same component the dedicated Change PDF Page Size tool uses, not a second implementation, so the two pages cannot end up describing the same operation differently — including its one real caveat, which is that a form field's stored appearance and the font size recorded with it are not rewritten, so a field that is filled in again after the resize can have its text redrawn too small for the box. The rectangles themselves move and scale with the content, so links and fields stay over what they belong to. File size makes the document smaller on disk without changing how a single page looks: objects nothing references any more are dropped, streams that arrived with no compression at all are deflated, and the file is repacked into object streams behind a cross-reference stream. Be clear about what that second half is not. It has no image encoder — a stream that already carries a filter, which is every embedded JPEG, is skipped by design — so it never re-encodes or downsamples a photograph, and a PDF that is mostly photos or scanned pages often comes back the same size to the byte. The wins come from structure, and on a document carrying wasted objects or raw streams they can be a third or more. There is no quality slider and no target size: you cannot ask it for under 500 KB.
