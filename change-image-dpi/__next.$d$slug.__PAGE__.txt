That is why this tool never decodes your image. It edits the header fields in place — a PNG's pHYs chunk and, where the file carries one, its eXIf resolution tags; a JPEG's JFIF density and its EXIF resolution tags — and hands the same compressed image data back, so what you download is your file with a different number in it rather than a re-encode. Writing only one of a file's two fields is the classic way to get this wrong: where a JPEG carries both, readers believe the EXIF one, so setting the JFIF alone looks right in a preview and changes nothing in InDesign. A PNG that carries an eXIf chunk behaves the same way — measured here, not assumed, because writing pHYs alone on such a file is a silent no-op. Both fields are written, in both formats.
