5a:T89d,A PDF form is not a picture of a form. Somewhere inside the file is an AcroForm dictionary listing named fields, and this tool reads that list and gives you one control per field: a box to type in for a text field, a tick for a check box, a set of radio buttons for a radio group, a menu for a dropdown, and a multi-select for a list box. Fields the document marks read-only are listed with their stored values and locked. Push buttons, signature fields and anything the engine cannot identify are shown too, each with a line saying why there is nothing there to fill in. Only the fields you actually change are written, and that matters more than it sounds. Writing to a field makes the engine redraw it in a standard Helvetica, keeping its colour, size and alignment but replacing whatever font the document's author picked, so re-sending a value you never edited would restyle a field for nothing. No value you did not touch is altered. When the answers are in, you can also flatten the form. Flattening bakes every field into the page and then removes the fields, which is what people mean by wanting a copy nobody can edit: the text stays real, selectable text rather than turning into a picture, and the result cannot be filled in again. That option is refused for some documents. A field with no stored appearance makes the underlying flatten fail part-way through and leaves a file that will not save at all, so this page names those fields and turns the box off rather than letting you find out afterwards. Filling still works on those documents, and the form stays interactive. Two limits are worth knowing before you start. Field text is drawn with a standard PDF font that covers the Latin alphabet, accented letters, curly quotes, dashes and the euro sign; Chinese, Japanese, Korean, Cyrillic, Greek, Arabic and emoji cannot be encoded at all, so the page checks what you type and stops the run instead of failing halfway through it. And this cannot create a form. A document with lines and boxes drawn on the page has no fields in it, and nothing here adds any — if the form dictionary is missing, your file is handed back untouched.
