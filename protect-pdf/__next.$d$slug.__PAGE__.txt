3c:T84f,A contract going out by email, a payslip, a scan of a passport — some documents should not open for whoever the message gets forwarded to. This page writes a password into the PDF itself using qpdf, the Apache-2.0 command-line PDF tool, compiled to WebAssembly and run inside your tab. Type a password, confirm it, and the document is encrypted with AES-256. AES-128 is offered for readers old enough not to understand the newer scheme, and RC4 — which the format still permits and which is broken — is never offered at all. Two passwords exist in a PDF and the difference matters. The user password is the one a reader is prompted for; the owner password is the one that lets a tool change the security settings afterwards. qpdf refuses to write a 256-bit file that has a user password and no owner password, so unless you set a separate owner password the tool uses the one you typed for both. That is the honest default: it is what most people mean, and it is what happens elsewhere without being said out loud. Now the limits, because they are the whole reason to read this. A password stops someone opening the file. It does not stop the person you gave the password to from opening it and saving a copy with the password taken off — this site has a page that does exactly that. It does not stop a screenshot, a photograph of the screen, or a forwarded printout. Restrictions on printing and copying can be written in alongside the password, but those are advisory flags a reader may honour or ignore, and PDF Permissions is the page that explains what they really are. There is no reset here. If you lose the password the document is gone, which is what encryption means and why nothing on this site can help you afterwards. A password longer than 127 bytes is refused before anything is written, because qpdf would accept it, encrypt with it, and then never let it back in. And a file that already carries a password has to be unlocked first — qpdf will not re-encrypt one, so the tool checks before it runs rather than failing halfway.
